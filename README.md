# Super Joey Foundation Philadelphia

Public website for the Philadelphia chapter of the Super Joey Foundation.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Update public text

Chapter wording, activities, officers, upcoming dates, past recaps, and the donation link live in `lib/content.ts`.

Set `donationUrl` to the approved giving link. Leave it as an empty string until that link is ready. Add an officer only after that person has agreed to be listed.
